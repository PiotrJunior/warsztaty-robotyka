Robotyka i symulacje robotów

Symulator fizyki MuJoCo, regulatory PID, kamery i markery ArUco, filtr Kalmana.

⬇ Pobierz paczkę na dzień 2warsztaty-robotyka-dzien2.zip · dzień 1 już rozwiązany

W tej paczce dzień 1 jest rozwiązany (PID, sterownik drona działają), a zadania dnia 2 czekają na Ciebie. Rozpakuje się do nowego folderu warsztaty-robotyka-dzien2, więc Twój dotychczasowy kod zostaje nietknięty.
Wolisz dalej pracować na swoim kodzie? W starym folderze wpisz uv run python pobierz_dzien.py 2, żeby dobrać tylko nowe zadania.

Instalacja

  1. Zainstaluj uv. Na Linuksie i macOS w terminalu: 
    curl -LsSf https://astral.sh/uv/install.sh | sh
    Jeśli nie masz curl (np. Ubuntu), użyj wget: 
    wget -qO- https://astral.sh/uv/install.sh | sh
    Na Windowsie w PowerShellu: 
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  2. Zamknij i otwórz terminal ponownie. Rozpakuj paczkę, wejdź do jej folderu (warsztaty-robotyka-dzien2) i wpisz uv sync.
  3. Tylko Ubuntu/Linux: wpisz raz poniższą komendę, a potem zamknij i otwórz terminal. Bez tego okno symulacji może się wysypać z błędem GLib-GIO-ERROR … antialiasing. 
    echo 'export PYGLFW_LIBRARY_VARIANT=x11' >> ~/.bashrc
  4. Sprawdź instalację: uv run python sprawdz_instalacje.py (na macOS: uv run mjpython sprawdz_instalacje.py). Na końcu powinno być Wszystko gotowe! :)

Więcej, w tym co zrobić, gdy coś nie działa, znajdziesz w pliku README.md w paczce.

Rano dnia 3 dobierz nowe zadania: w folderze warsztatów wpisz uv run python pobierz_dzien.py 3. Twój kod zostanie nietknięty.
